# Cartes Volley (version web)

Appli web installable pour créer des cartes de joueurs de volley avec radar hexagonal.

**Installer sur iPhone** : ouvre le site dans Safari → Partager → Sur l'écran d'accueil.
**Installer sur Android** : Chrome → ⋮ → Ajouter à l'écran d'accueil.

Les cartes sont enregistrées sur le téléphone, jamais dans ce dépôt.
